
# Sistema de Apoio ao ENADE

**Disciplina:** Requisitos e Modelagem de Sistemas  
**Semestre:** 2026.2  
**Grupo:** 1  
**Instituição:** Universidade de Fortaleza (UNIFOR)

## Sobre o Projeto

O projeto tem como objetivo especificar um Sistema de Apoio ao ENADE, oferecendo recursos para auxiliar estudantes na preparação para o exame.

Entre as funcionalidades propostas estão:

- Consulta e filtragem de questões anteriores;
- Realização de simulados cronometrados;
- Visualização de gabaritos comentados;
- Acompanhamento do desempenho;
- Fórum de discussão de questões;
- Gerenciamento de questões e usuários.

## Sprint 1 — Milestone M1

**Período:** 20/10/2026 a 02/11/2026

A primeira sprint contempla a elicitação de requisitos, a definição das funcionalidades e a modelagem UML inicial.
