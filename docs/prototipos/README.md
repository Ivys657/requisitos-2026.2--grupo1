# Protótipo — Sprint 2

Ferramenta escolhida: **Google Stitch** (ou exportação para Figma, se necessária).

## Como usar

1. Revisar o SRS e os casos de uso; ajustar pendências antes da versão final.
2. Copiar o conteúdo de [prompt-stitch.txt](prompt-stitch.txt) para o Stitch.
3. Gerar telas em blocos menores caso o Stitch não gere todas de uma vez.
4. Conectar as telas e usar a visualização `Play` para testar os fluxos A–D.
5. Exportar/registrar wireframes e compartilhar o protótipo navegável.
6. Acrescentar aqui o link final e evidências de teste.
