# UC09 — Recuperar senha

> **Sprint 2 — versão revisada para validação do grupo.** Especificação funcional e roteiro para o protótipo; não é implementação executável. Referências: `04-requisitos.md`, `05-regras-de-negocio.md`, `07-uml.md`.

| Campo | Definição |
|---|---|
| Identificador | UC09 |
| Caso de uso original da P1 | Recuperar senha |
| Ator(es) | Usuário com conta |
| Requisitos relacionados | RF03 |
| Necessidades relacionadas | N02 |
| Regras aplicáveis | RN15 (segurança de autenticação, quando aplicável) |
| Objetivo | Solicitar recuperação de senha via e-mail sem revelar indevidamente a existência de contas. |
| Pré-condições | Usuário não autenticado, na tela de login. |
| Pós-condições | Instruções de recuperação solicitadas, ou erro informado; senha só alterada após validação da recuperação. |

## Entradas

- E-mail
- Nova senha na etapa de redefinição

## Saídas

- Mensagem de solicitação
- Tela ilustrativa de redefinição
- Confirmação ou mensagem de expiração de link

## Fluxo principal

1. O usuário clica **Esqueci minha senha**.
2. O sistema solicita e-mail.
3. O usuário informa e-mail e envia.
4. O sistema apresenta confirmação genérica da solicitação, sem revelar se a conta existe.
5. Em etapa posterior demonstrativa, o usuário abre o link válido e define nova senha.
6. O sistema confirma a redefinição e oferece retorno ao login.

## Fluxos alternativos, exceções e validações

- **A1 — E-mail ausente ou inválido:** solicitar correção.
- **A2 — Link inválido/expirado:** oferecer nova solicitação; prazo de validade não está definido nos requisitos.
- **A3 — Falha no serviço de envio:** exibir aviso de indisponibilidade; protótipo não envia e-mail de verdade.

## Critérios de aceite para inspecionar no protótipo

- Fluxo Login → Recuperar → Redefinir → Login é navegável.
- A confirmação não confirma existência de conta.

## Navegação / telas previstas para o Stitch

Login → Recuperar senha → Redefinir → Login

## Observações de consistência

- Bloqueio da RN15 refere-se a tentativas de login inválidas; não inventar bloqueio extra de recuperação.
