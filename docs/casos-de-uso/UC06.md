# UC06 — Ver gabarito comentado

> **Sprint 2 — versão revisada para validação do grupo.** Especificação funcional e roteiro para o protótipo; não é implementação executável. Referências: `04-requisitos.md`, `05-regras-de-negocio.md`, `07-uml.md`.

| Campo | Definição |
|---|---|
| Identificador | UC06 |
| Caso de uso original da P1 | Ver gabarito comentado |
| Ator(es) | Estudante |
| Requisitos relacionados | RF10 |
| Necessidades relacionadas | N08 |
| Regras aplicáveis | RN06, RN17 |
| Objetivo | Consultar a alternativa correta e explicação pedagógica no momento permitido. |
| Pré-condições | Questão individual respondida ou simulado encerrado (RN06). |
| Pós-condições | Gabarito e justificativa apresentados; consulta não modifica resposta. |

## Entradas

- Questão previamente respondida ou integrante de simulado encerrado

## Saídas

- Alternativa correta
- Comparação com a resposta do estudante
- Explicação pedagógica e referência da questão

## Fluxo principal

1. Após responder individualmente ou encerrar o simulado, o estudante solicita o gabarito.
2. O sistema verifica que o momento de divulgação é permitido (RN06).
3. O sistema apresenta alternativa correta e justificativa cadastrada.
4. O estudante consulta a explicação e volta ao estudo, resultado ou próxima questão.

## Fluxos alternativos, exceções e validações

- **A1 — Questão não respondida e simulado não concluído:** não mostrar gabarito.
- **A2 — Explicação ausente:** indicar explicitamente que o comentário ainda não está disponível, sem inventar justificativa.

## Critérios de aceite para inspecionar no protótipo

- Interface bloqueia ou omite gabarito antes do momento permitido.
- Mostra alternativa correta, comparação e explicação fictícia identificada.

## Navegação / telas previstas para o Stitch

Questão respondida / Resultado → Gabarito comentado → Voltar

## Observações de consistência

- Distinguir comentário pedagógico de professor (UC11) do gabarito oficial da questão.
