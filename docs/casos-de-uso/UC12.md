## Entradas

- Período (opcional)
- Componente (opcional)
- Curso autorizado determinado pelo perfil

## Saídas

- Indicadores e gráficos agregados e anônimos
- Estado de dados insuficientes/ausentes

## Fluxo principal

1. O coordenador acessa **Desempenho do curso**.
2. O sistema identifica o curso ao qual o coordenador está vinculado (RN11).
3. O coordenador define período e componente, se desejar.
4. O sistema calcula agrupamentos do curso sem nomes ou notas individuais.
5. Somente grupos com pelo menos **cinco estudantes** têm indicadores divulgados (RN11).
6. O coordenador consulta gráficos agregados.

## Fluxos alternativos, exceções e validações

- **A1 — Menos de cinco estudantes no agrupamento:** não revelar métricas; mostrar “Dados insuficientes para exibição preservando a privacidade” (RN11).
- **A2 — Curso não autorizado:** bloquear acesso.
- **A3 — Sem resultados:** mostrar estado vazio sem informações identificáveis.

## Critérios de aceite para inspecionar no protótipo

- Exibe gráfico apenas com dados simulados de grupo com ≥5 estudantes.
- Estado <5 oculta métricas.
- Não aparecem nomes, matrículas, notas ou ranking individual de estudantes.

## Navegação / telas previstas para o Stitch

Painel coordenador → Filtros do curso → Gráficos / Dados insuficientes

## Observações de consistência

- Dados fictícios podem indicar 12 participantes para demonstrar um grupo permitido.
