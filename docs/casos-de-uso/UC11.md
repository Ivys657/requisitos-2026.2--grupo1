> **Sprint 2 — versão revisada para validação do grupo.** Especificação funcional e roteiro para o protótipo; não é implementação executável. Referências: `04-requisitos.md`, `05-regras-de-negocio.md`, `07-uml.md`.

| Campo | Definição |

| Requisitos relacionados | RF11 |
| Necessidades relacionadas | N08 |

| Objetivo | Cadastrar ou editar explicação pedagógica associada a uma questão. |
| Pré-condições | Professor autenticado e autorizado; questão existente. |
| Pós-condições | Comentário pedagógico atualizado se autorizado e válido. |

## Entradas

- Questão de referência
- Texto da explicação pedagógica

## Saídas

- Comentário atualizado
- Confirmação/erro de autorização ou validação

## Fluxo principal

1. O professor acessa o painel e localiza uma questão.
2. Abre **Comentário pedagógico** da questão.
3. Insere ou edita o texto explicativo.
4. O sistema valida texto e autorização do professor (RN14).
5. O sistema registra a alteração e confirma.
6. O comentário só fica acessível ao estudante no momento de liberação do gabarito (RN06).

## Fluxos alternativos, exceções e validações

- **A1 — Texto vazio:** impedir publicação e solicitar explicação.
- **A2 — Professor não autorizado:** impedir edição (RN14).
- **A3 — Questão inexistente:** não salvar comentário sem vínculo.

## Critérios de aceite para inspecionar no protótipo

- Painel permite escolher questão e editar explicação.
- Há erro de permissão e de campo vazio.
- Estudante não recebe gabarito antecipadamente.

## Navegação / telas previstas para o Stitch

Painel professor → Questão → Editar comentário → Confirmar

## Observações de consistência

- O usuário Professor não gerencia o cadastro completo de questões pelo UC10 (RN03).
