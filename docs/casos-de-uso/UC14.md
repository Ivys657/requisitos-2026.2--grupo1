## Entradas

- Conta selecionada
- Operação: ativar, desativar, alterar perfil
- Perfil de destino quando aplicável

## Saídas

- Lista atualizada de usuários
- Confirmação ou mensagem de erro

## Fluxo principal

1. O administrador abre **Gerenciar usuários**.
2. O sistema exibe lista pesquisável de contas.
3. O administrador escolhe uma conta e a operação pretendida.
4. O sistema valida autorização e a regra de **um perfil principal por conta** (RN01).
5. O administrador confirma a alteração.
6. O sistema atualiza a conta e informa o resultado.

## Fluxos alternativos, exceções e validações

- **A1 — Conta inexistente:** exibir estado sem resultados.
- **A2 — Perfil não permitido:** bloquear alteração.
- **A3 — Desativação:** pedir confirmação para evitar erro operacional.
- **A4 — Exclusão de dados:** demandas LGPD (RN16) devem seguir procedimento próprio ainda não especificado; não equiparar desativação à exclusão.

## Critérios de aceite para inspecionar no protótipo

- Administrador pode demonstrar ativar, desativar e alterar perfil.
- A interface nunca mostra dois perfis principais para a mesma conta.
- Desativação não é apresentada como exclusão definitiva de dados.
