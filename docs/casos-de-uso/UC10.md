# UC10 — Gerenciar questões

> **Sprint 2 — versão revisada para validação do grupo.** Especificação funcional e roteiro para o protótipo; não é implementação executável. Referências: `04-requisitos.md`, `05-regras-de-negocio.md`, `07-uml.md`.

| Campo | Definição |
|---|---|
| Identificador | UC10 |
| Caso de uso original da P1 | Gerenciar questões |
| Ator(es) | Administrador |
| Requisitos relacionados | RF09; RF05 como regra de organização |
| Necessidades relacionadas | N04 |
| Regras aplicáveis | RN03, RN04, RN05, RN17 |
| Objetivo | Cadastrar, editar, importar ou desativar questões e manter vínculos obrigatórios. |
| Pré-condições | Administrador autenticado e autorizado. |
| Pós-condições | Questão criada/alterada/importada ou desativada, sem apagar histórico anterior. |

## Entradas

- Ação escolhida: cadastrar, editar, desativar, importar
- Ano e edição da prova
- Curso/área e componente
- Enunciado e alternativas
- Gabarito e explicação, quando disponível
- Dados de importação simulada

## Saídas

- Listagem atualizada
- Confirmação ou inconsistências da operação
- Estado ativo/desativado

## Fluxo principal

1. O administrador acessa **Gerenciar questões** (RN03).
2. Escolhe cadastrar, editar, importar ou desativar.
3. O sistema exibe formulário ou painel correspondente.
4. O administrador informa dados, incluindo ano, curso/área e componente obrigatórios (RN04).
5. O sistema valida informações, associa fonte/edição do INEP (RN17) e executa operação.
6. O sistema mostra a listagem atualizada e confirmação.

## Fluxos alternativos, exceções e validações

- **A1 — Usuário sem perfil de administrador:** impedir operação (RN03).
- **A2 — Vínculo obrigatório ausente:** rejeitar e destacar ano, curso/área ou componente (RN04).
- **A3 — Desativar:** a questão deixa de aparecer em novas buscas/simulados, mas permanece nos históricos já realizados (RN05).
- **A4 — Importação com falha:** mostrar registros rejeitados, sem alegar importação real no protótipo.
- **A5 — Questão duplicada:** avisar sobre possível duplicidade para revisão (critério exato ainda a definir).

## Critérios de aceite para inspecionar no protótipo

- Tela lista questões e permite demonstrar cadastro/edição/desativação.
- Formulário exige ano, curso/área, componente.
- Desativação mostra aviso de preservação do histórico.

## Navegação / telas previstas para o Stitch

Admin → Questões → Novo/Editar → Confirmar → Lista

## Observações de consistência

- Curso → disciplina → conteúdo → material/questão permanece hipótese não aprovada; não exigir esses cadastros extras.
